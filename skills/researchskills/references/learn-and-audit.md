# Explain foundations, learn research judgment, and audit the library

For ordinary explanations, follow the selected 1/2/3 depth from `SKILL.md` and answer the user's question directly. Establish only the prerequisites needed to understand this answer. Connect terminology and equations to observable quantities, assumptions and limits. Use authoritative teaching sources for established foundations and inspected primary papers for specific research findings. Do not invent chapter, page, figure or source details when access is unavailable.

## A learning plan only when requested

Start from the work the user wants to perform and reuse demonstrated abilities. Work backward to the few prerequisites that affect that task; distinguish what is needed now from what can be learned alongside it or deferred. For each necessary block, connect the core idea, a verified resource and locator, and a useful research task. A worked derivation, control prediction or evidence comparison may be more helpful than a fixed curriculum. Label toy calculations and exercises as illustrations rather than new scientific evidence.

Provide an assessment only when requested. Use a fresh applied task and respond to the actual answer before suggesting remediation. Distinguish an uncertainty about notation or implementation from a conceptual error. An unanswered check stays unassessed and does not block independent research work. Keep any personal progress record outside the installed skill. Stop adding preparation once it no longer changes the next research decision.

Domain learning here means building reusable evidence, practicing interpretation, and evaluating retrieval and reasoning. It does not update model weights or guarantee recall in a future chat. Durable knowledge consists of saved external artifacts that later work explicitly retrieves.

## Learn from the reasoning, not just the result

For each important study, extract the chain: question → design → measurement → observation → competing interpretations → discriminating control → conclusion and limits. Compare papers that reach different assignments under different conditions. Identify which differences arise from sample structure or preparation, which from measurement definitions, and which remain unresolved.

Turn the user's research goals into short exercises when training is requested: infer what a control can exclude, predict how an alternative mechanism would change a measurement, critique a causal claim, or draft a paragraph with traceable citations. Use unresolved questions as explicit hypotheses, not established facts. Store useful principles with linked examples in the external library, keeping the installed method free of fixed material-specific values.

## Evaluate without leaking the answer

For a requested evaluation, keep a small held-out set of papers, figures, or sample conditions separate from the examples used to develop the interpretation rules. Define the task and acceptance criteria before examining the answers. Hold out by study where practical; moving a figure from the same paper to a test split does not create independent evidence.

Assess observable behavior: correct material and sample match, preserved units and value type, correct source locator, calibrated claim strength, recognition of overlap/conflicts, and willingness to leave an unsupported assignment unresolved. Include ambiguous and out-of-scope examples; accurate abstention is useful. Compare against explicit source-backed answers, record errors, and update the reusable rule only when the error supports the change. Do not turn one paper's value into a universal threshold.

If independent agent evaluation is useful and available, provide the task, skill, and minimum source artifacts without giving the expected conclusion. Keep the run within authorized sources and output locations. Automated checks can validate schemas and links; they cannot by themselves validate scientific interpretation.

## Audit coverage and evidence quality separately

- **Coverage:** Does the catalog reconcile the declared group/topic/date scope and version deduplication? Are inaccessible papers still visible?
- **Provenance:** Can each important record be traced to an actual inspected source location? Are source access and full-reading claims accurate?
- **Scientific inference:** Are observations separated from authors' assignments and our evaluation? Are controls, conflicts, and transfer limits retained?
- **Reuse:** Can a later writing or analysis task find the relevant note and verify the claim without trusting a free-floating summary?

Report concrete counts and failed examples rather than an unexplained composite score. Preserve the benchmark version and source cutoff so later changes can be compared. Corpus coverage, extraction accuracy, and interpretive success should not be collapsed into one assertion of “trained.”
